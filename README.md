# 🔪 Swiss Army Knife (Free Edition)

A lightweight, high-performance local desktop tool suite built with Python and Tkinter. Featuring a heavy-duty local PDF workstation and a real-time cloud community hub for sharing pixel art and color swatches.

## 🚀 Features in this Edition
* **📑 PDF Studio**: Extract all embedded images, dump text to `.txt`, or pull document stats and metadata completely locally.
* **🌐 Community Cloud Feed**: Publish your custom color palettes and ASCII/pixel art posts to a live cloud feed and browse creations shared by other users worldwide.
